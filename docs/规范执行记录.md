# 项目规范执行记录

执行日期：2026 年 11 月 16 日。依据仓库内的 [项目采用说明](../.ai-dev-standards/PROJECT.md)、通用工程、中文注释、React 与 FastAPI 规范。本次覆盖现有第一期工作台及其 API，项目差异记录在采用说明中。

## 本次改动

- React 工作台使用 Zustand 管理会话、业务选择与跨页复用，使用 React Router 管理 Hash 路由和可分享筛选，使用 UnoCSS 处理公共布局、间距和面板样式。
- 常规业务请求经领域 Service 进入统一 Axios Client。入口维护同源凭证、超时、取消及错误归一化；页面切换后隔离旧响应，写请求由调用方按业务规则重试。
- FastAPI 按应用工厂、Router、用例、领域规则和输入输出契约组织。案例与材料查询在存储层过滤可见范围；草稿重放和等待模型后的写入重新核对权限。并发编辑依赖版本条件，界面保留未保存输入供人工合并。
- 实际路由生成 OpenAPI、前端类型和响应运行时 Schema。修改接口需同步运行 `npm run contract:generate`，并提交三个生成产物。

## 浏览器验收

使用 Chrome 打开 FastAPI 提供的生产构建，以临时 SQLite 与合成数据执行。桌面验证材料录入、整理和提交草稿、保存已验证并发布的案例，以及读取历史版本。并发编辑时，旧版本保存返回 409，草稿原样保留；读取新版本、人工合并并确认后可继续保存。

桌面验证键盘登录、旧 Hash 跳转、搜索与验证筛选刷新恢复、案例深链、浏览器前进后退和 Escape 关闭详情。验证本地规则分析引用已验证案例，并可保存实际反馈，在「我的提问」中看到已解决状态。

在 390 px 窄屏验证问题页没有水平溢出、案例抽屉未超出视口且可关闭，以及退出后刷新仍保持未登录。整轮自动化浏览器复验未捕获页面脚本异常。

使用独立临时 SQLite 和合成数据在浏览器完成「提问 → 保存反馈 → 生成新案例草稿 → 人工补齐字段 → 确认有效性 → 发布」；继续添加反馈并选择已发布目标，对照字段、人工采用原值和合并修改，发布到原案例 v2。案例历史保留 v1、v2，原始依据页可读取已采用反馈；待确认页面可查看和重新打开已发布的新增与修订草稿。

390 px 窄屏实测对话框宽 374 px，页面宽 390 px，无水平溢出；逐字段对照、编辑、提交及修订发布可完成。键盘可选择修订用途和目标案例，Escape 可触发未保存关闭保护。

本次仍使用本地规则模式。真实模型质量、正式部署和 PostgreSQL 本轮兼容性待实际环境验收；模型故障、权限变化与并发分支通过可控测试替身和隔离数据库验证。详细操作与接口见 [反馈案例草稿](反馈案例草稿.md)。
